# Enterprise-E-Commerce-Relational-Database-Architecture
Enterprise-level e-commerce database design using SQL Server, T-SQL, relational modeling, and query optimization.

This project demonstrates the design and development of an online retail database using Microsoft SQL Server and T-SQL.

### Key Features
- Relational database design with Customers, Products, Categories, Orders, and OrderItems tables.
- Primary keys, foreign keys, and sample data.
- SQL queries for sales analysis, customer spending, product performance, and inventory tracking.
- Joins, aggregate functions, subqueries, and window functions.
- Triggers and a ChangeLog table to track INSERT, UPDATE, and DELETE operations.
- Indexing concepts for query performance optimization.

### Technologies Used
- Microsoft SQL Server (MSSQL)
- T-SQL
- SQL Server Management Studio (SSMS)

### Project Objective
To develop practical SQL skills by building a relational database and performing common retail data management and reporting operations.
